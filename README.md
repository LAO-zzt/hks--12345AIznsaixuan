> **2026 百所高校顺德行 · 创青春 AI 黑客松 · 企业解决方案赛道 E01 命题作品**
> （命题方：顺德区政数局 · 12345 热线多频工单识别）
>
> AI 自动聚类海量 12345 热线工单，识别「多频事件」：同一区域、同类问题自动归集，频次合并计数，提供趋势、区域分布与关联工单核查，辅助政务部门快速发现重复投诉热点。

## 一、环境准备（3 步）

```bash
# 1. 克隆项目
git clone https://github.com/LAO-zzt/hks--12345AIznsaixuan.git
cd hks

# 2. 安装依赖（Python 3.9+，开发环境实测 3.12）
pip install -r requirements.txt

# 3. 放入工单数据（CSV / xlsx 均可）
#    把数据文件放到 data/input/ 目录下
```

> 没有数据文件也能跑：页面支持上传，或用飞书在线表格作为数据源（需配置密钥，见下文）。

## 二、配置密钥（必读 · 安全）

本项目**不把任何密钥提交到仓库**。真实密钥放在 `textclean_module/config.yaml`，该文件已被 `.gitignore` 忽略。

```bash
# 复制模板，生成你的本地配置
cp textclean_module/config.example.yaml textclean_module/config.yaml
```

然后编辑 `textclean_module/config.yaml`，填入两处真实 Key（留空也能离线跑，只是没有 LLM / 高德增强）：

```yaml
llm:
  openai:
    api_key: "你的 DeepSeek Key"   # 留空则离线模式
gaode:
  api_key: "你的高德 Key"           # 留空则关闭 POI 验证
```

> ⚠️ **密钥与隐私红线**
> - `config.yaml` 已 gitignore，**切勿** `git add` 它，也不要把真实 Key 贴进任何 `.md` / 代码注释。
> - 仓库只保留 `config.example.yaml` 模板（空 Key 占位）。
> - 如需在团队间共享密钥，请用环境变量注入或私有配置，不要走 git。

## 三、启动

```bash
python webapp/server.py
```

浏览器打开 **http://127.0.0.1:8600**

## 四、演示动线（5 分钟）

1. **连接数据源**：右上角 ⚙ 设置 → 数据源下拉选择 `data/input/` 里的文件 → 点击「重新分析」（首次全量分析约 1~3 分钟，可点状态徽章看实时进度；之后秒开，结果已缓存）
2. **全局总览**：KPI 卡片（总工单 / 重复工单 / 多频事件）→ 趋势图 → 地图区域分布（缩放到 ≥12 级散开为具体点位）
3. **多频事件榜**：点击任一事件行 → 右侧展示事件详情（趋势、区域分布、多频识别依据、样例工单）
4. **工单工作台**：双击事件榜任意行或点击 KPI 卡片进入 → 按区域 / 主体 / 事件 / 多频状态组合筛选 → 单击工单行看详情
5. **工单详情**：AI 多频归集结论 + 脱敏原文 + **关联工单**（同地点其他重复投诉，点击互跳）→ 底部可导出 CSV / Excel

## 五、可选配置

**飞书数据源 / 推送**（不用可跳过，纯离线演示不受影响）：参考仓库内 `config.env.example` 配置飞书 App ID / Secret 即可。

## 六、技术说明

- **聚类主方案**：TF-IDF + 余弦相似度 + DBSCAN，零额外下载、中文短文本可解释，适合离线政务环境。
- 数据超过 1.5 万条自动切换大数据路线（标题规则分组 + 签名归并），十万级工单可跑（实测约 12.8 万条）。
- 所有 API 响应已做 PII 脱敏（姓名 / 手机号 / 身份证）。
- 地图底图：高德瓦片（国内访问稳定）。
- 结果缓存在 `data/output/cache/`，重启服务秒恢复；设置面板底部「清理缓存并重新分析」可全量重跑。
